# Smilebook

Fotografía clínica dental, archivo de casos, periodontograma y publicaciones.

Abre la app en https://juandelrosal98.github.io/smilebook/ y, desde Chrome en Android o Edge en Windows, elige «Instalar app» / «Añadir a pantalla de inicio».

Este repositorio solo contiene el código de la aplicación. **No contiene datos ni fotografías de pacientes**: esos datos se guardan en cada dispositivo (IndexedDB del navegador) y, si activas la copia en la nube, cifrados con tu contraseña en una carpeta privada de tu OneDrive.
